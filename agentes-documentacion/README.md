# agentes-documentacion

Bitácora de todo lo que hacen los agentes IA en este proyecto (CTF 2026-2).

- Una carpeta por agente: `claude/`, `codex/`, `antigravity/`, `ollama/`.
- Un archivo por día: `YYYY-MM-DD.md`.
- Cada acción se documenta inmediatamente después de realizarla con este formato:

```
## HH:MM — Título de la acción
**Acción:** qué se hizo
**Archivos tocados:** lista con ruta y motivo
**Contexto:** por qué, qué problema resuelve
**Pendiente / Próximo paso:** qué falta si quedó incompleto
**Estado:** ✅ Completado | 🔄 En progreso | ⏸ Pausado | ❌ Fallido
```

Ver [INSTRUCCIONES-PARA-AGENTES.md](INSTRUCCIONES-PARA-AGENTES.md) para el onboarding.
